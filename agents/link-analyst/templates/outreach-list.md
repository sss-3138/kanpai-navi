## 3. メールテンプレート

### 3.1 寄稿提案

```
件名: 【寄稿のご提案】{{相手サイト名}}読者に向けた{{テーマ}}の記事について

{{担当者名}} 様

突然のご連絡を失礼いたします。
お酒のトレンドメディア「カンパイなび」(https://kanpai-navi.com/) の{{担当者名}}と申します。

日頃から {{相手サイト名}} の記事を拝読しており、
特に「{{具体的な記事タイトル}}」は非常に参考になりました。

このたび、{{相手サイト名}} の読者の皆様にもお役に立てるのではないかと思い、
{{テーマ}}に関する記事の寄稿をご提案させていただきたくご連絡いたしました。

【ご提案内容】
・テーマ: {{記事テーマ}}
・想定文字数: {{文字数}}文字程度
・想定読者: {{ターゲット}}

ご興味がございましたら、詳細な企画案をお送りいたします。
ご検討のほど、よろしくお願いいたします。

カンパイなび
{{担当者名}}
```

### 3.2 データ引用・情報提供

```
件名: 【情報提供】{{テーマ}}に関する最新データのご紹介

{{担当者名}} 様

突然のご連絡を失礼いたします。
お酒のトレンドメディア「カンパイなび」の{{担当者名}}と申します。

{{相手サイト名}}で公開されている「{{記事タイトル}}」を拝読いたしました。
{{記事の良い点の言及}}

関連して、弊メディアで公開している以下の記事・データが
貴記事の読者の方にもお役に立つのではないかと考え、ご連絡いたしました。

・{{自サイト記事タイトル}}: {{URL}}
  — {{記事の概要と相手記事との関連性}}

もし参考になるようでしたら、引用・リンクなどの形でご紹介いただけますと幸いです。

カンパイなび
{{担当者名}}
```

### 3.3 リンク切れ通知

```
件名: 【ご連絡】貴サイト記事内のリンク切れについて

{{担当者名}} 様

突然のご連絡を失礼いたします。
お酒のトレンドメディア「カンパイなび」の{{担当者名}}と申します。

貴サイトの「{{記事タイトル}}」（{{URL}}）を拝読していた際、
以下のリンクがリンク切れ（404）になっていることに気づきましたのでご連絡いたしました。

・リンク切れURL: {{broken_url}}
・アンカーテキスト: {{anchor_text}}

ご参考までに、同様のテーマを扱った弊メディアの記事をご紹介いたします。
・{{自サイト記事タイトル}}: {{URL}}

リンクの差し替え先としてご検討いただけますと幸いです。

カンパイなび
{{担当者名}}
```

読者の方が直接アクセスしやすくなり、双方にとってメリットがあると考えております。

ご検討のほど、よろしくお願いいたします。
