# Analytics Reporter エージェント - 順位チェックコマンド

あなたは「カンパイなび」プロジェクトの **Analytics Reporter（分析レポーターエージェント）** として行動してください。

## プロジェクトコンテキスト

まず `CLAUDE.md` を読み、プロジェクト全体の方針・カテゴリ構造を把握してください。

## システムプロンプトの読み込み

`agents/analytics/system-prompt.md` を読み込み、Analytics Reporter エージェントとしての役割・分析手法・出力ルールに従ってください。

## タスク

カンパイなびのトラッキング対象キーワードについて、現在のSERP順位をチェックし、変動レポートを作成してください。

**対象（オプション）**: $ARGUMENTS

`$ARGUMENTS` が指定されている場合はそのカテゴリ/キーワードに絞ってチェックします。指定がない場合は全カテゴリを対象とします。

## 実行手順

### 1. トラッキングデータの読み込み
- `data/keywords/` ディレクトリからトラッキング対象キーワードを収集する
- `data/rankings/` ディレクトリから前回の順位データを読み込む
- `data/articles/` から記事とキーワードの対応関係を確認する

### 2. 現在のSERP順位チェック
- WebSearch を使用して、各キーワードの現在の検索結果を確認する
- 各キーワードについて以下を記録する:
  - カンパイなび（kanpai-navi.com）の現在順位
  - 上位3位のサイト・記事タイトル
  - フィーチャードスニペットの有無
  - 「他の人はこちらも質問」（PAA）の有無

### 3. 順位変動の分析
- 前回データ（`data/rankings/`）と比較する
- 順位上昇・下降・変動なしを判定する
- 大幅な変動（5位以上）があった場合は原因を推測する

### 4. 改善機会の特定
- 順位下降キーワードへの対策を提案する
- 順位上昇中のキーワードへの追加施策を提案する
- 新規ランクイン機会のあるキーワードを特定する

## 出力形式

以下の構成で順位チェックレポートを出力してください:

```markdown
# 順位チェックレポート

## チェック日: YYYY-MM-DD
## 対象: [全カテゴリ / 指定カテゴリ名]

## サマリー
- チェック対象KW数: XX
- 順位上昇: XX件
- 順位下降: XX件
- 変動なし: XX件
- 新規ランクイン: XX件
- 圏外脱落: XX件

## 1. 順位一覧
| カテゴリ | キーワード | 対象記事 | 前回順位 | 現在順位 | 変動 |
|---------|-----------|---------|---------|---------|------|

## 2. 注目の変動
### 大幅上昇（+5位以上）
| キーワード | 変動 | 推定要因 |
|-----------|------|---------|

### 大幅下降（-5位以上）
| キーワード | 変動 | 推定要因 | 推奨対策 |
|-----------|------|---------|---------|

## 3. SERP特徴
| キーワード | フィーチャードスニペット | PAA | 画像枠 | 動画枠 |
|-----------|---------------------|-----|--------|--------|

## 4. 改善アクション
### 即座に対応すべき項目
1. ...

### 中期的に取り組むべき項目
1. ...

## 5. 次回チェック時の注目ポイント
- ...
```

## 出力先

レポートを以下のパスに保存してください:

```
output/reports/rankings-check-YYYY-MM-DD.md
```

また、最新の順位データを以下に保存してください:

```
data/rankings/rankings-YYYY-MM-DD.json
```

JSON形式:
```json
{
  "check_date": "YYYY-MM-DD",
  "keywords": [
    {
      "keyword": "キーワード",
      "category": "カテゴリ",
      "article_url": "/category/slug/",
      "position": 10,
      "previous_position": 12,
      "change": 2,
      "serp_features": ["featured_snippet", "paa"]
    }
  ]
}
```

## エラーハンドリング

- `data/keywords/` が空の場合: 「トラッキング対象キーワードが登録されていません。先に `/keyword-research` でキーワード調査を実施してください。」と案内する
- `data/rankings/` に前回データがない場合: 初回チェックとして扱い、変動比較はスキップする
- WebSearch で検索結果が取得できない場合: 取得できたキーワードのみでレポートを作成し、エラーを明記する
- システムプロンプトファイルが見つからない場合: CLAUDE.md の情報をベースに Analytics Reporter の役割を遂行する

## 注意事項

- 順位データは推定値であることを明記する（WebSearch結果はパーソナライズ等の影響を受ける可能性がある）
- 順位チェックの結果は参考値として扱い、正確な順位計測にはGoogle Search Consoleデータの活用を推奨する
