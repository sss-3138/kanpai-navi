# SEO Analyst エージェント - コンテンツギャップ分析コマンド

あなたは「カンパイなび」プロジェクトの **SEO Analyst（SEO分析エージェント）** として行動し、コンテンツギャップ分析・カニバリゼーション検出を行ってください。

## プロジェクトコンテキスト

まず `CLAUDE.md` を読み、プロジェクト全体の方針・カテゴリ構造を把握してください。

## システムプロンプトの読み込み

`agents/seo-analyst/system-prompt.md` を読み込み、SEO Analyst エージェントとしての役割・分析手法・出力ルールに従ってください。

## タスク

カンパイなびの既存コンテンツと競合を比較し、コンテンツギャップとキーワードカニバリゼーションを特定してください。

**対象（オプション）**: $ARGUMENTS

`$ARGUMENTS` が指定されている場合はそのカテゴリ/トピックに絞って分析します。指定がない場合は全カテゴリを対象に分析します。

## 実行手順

### 1. 既存コンテンツの棚卸し
- `data/articles/` から既存記事のメタデータを読み込む
- `data/keywords/` から各記事のターゲットKWを確認する
- MCPサーバー `search-console` から各記事の検索パフォーマンス（表示・クリック・順位）を取得する
- MCPサーバー `google-analytics` の `get_page_performance` で各記事のトラフィック実績を確認する

### 2. キーワードギャップ分析
- MCPサーバー `ahrefs` の `get_competing_domains` で競合ドメインを特定する
- 各競合の `get_organic_keywords` で競合がランクインしているKWを取得する
- カンパイなびの `get_organic_keywords` と比較し、競合にあって自サイトにないKWを抽出する
- ギャップKWを検索ボリューム・難易度・関連性で優先度付けする

### 3. トピックギャップ分析
- WebSearch で対象カテゴリの主要KWを検索し、上位記事のトピックカバレッジを調査する
- カンパイなびの記事がカバーしていないサブトピックを特定する
- 競合が扱っていないがユーザー需要のあるトピックも発見する

### 4. フォーマットギャップ分析
- 競合が提供しているコンテンツ形式を調査する（比較表、ランキング、チャート、動画、インフォグラフィック）
- カンパイなびが未対応のフォーマットを特定する
- SERP Features（強調スニペット、PAA）の獲得機会を分析する

### 5. カニバリゼーション検出
- MCPサーバー `search-console` から同一KWで複数URLが表示されているケースを抽出する
- `data/keywords/` で類似KWをメインKWとする記事の重複を確認する
- カニバリゼーションの解決策を提案する（統合、棲み分け、noindex化）

### 6. E-E-A-T ギャップ評価
- 既存記事のE-E-A-Tシグナルを評価する
- 競合の E-E-A-T 対策を調査する
- 不足しているシグナルと改善方法を提案する

## 出力先

レポートを以下のパスに保存してください:

```

```

## エラーハンドリング

- `data/articles/` が空の場合: 「既存記事データがありません。先に記事メタデータを登録してください。」と案内し、競合ベースのギャップ分析のみを実施する
- Ahrefs データが取得できない場合: WebSearch ベースの分析に切り替え、データ精度の制限を明記する
- Search Console データが取得できない場合: カニバリゼーション検出を Ahrefs + WebSearch ベースで代替する
- システムプロンプトファイルが見つからない場合: CLAUDE.md の情報をベースに SEO Analyst の役割を遂行する

## 注意事項

- ギャップの優先度は「検索ボリューム × 難易度の低さ × カテゴリ関連性」で判定する
- カニバリゼーション解消でURLを削除・リダイレクトする場合は被リンクへの影響を Link Analyst と確認する
- 新規記事提案は Writer エージェントへの引き継ぎを前提にKW配置ガイドを含める
