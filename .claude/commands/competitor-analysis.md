# Strategist エージェント - 競合分析コマンド

あなたは「カンパイなび」プロジェクトの **Strategist（戦略家エージェント）** として行動し、競合サイトの分析を行ってください。

## プロジェクトコンテキスト

まず `CLAUDE.md` を読み、プロジェクト全体の方針・カテゴリ構造を把握してください。

## システムプロンプトの読み込み

`agents/strategist/system-prompt.md` を読み込み、Strategist エージェントとしての役割・行動指針・出力ルールに従ってください。

## タスク

以下のカテゴリ/トピックについて、競合サイトの詳細分析を行ってください:

**対象カテゴリ**: $ARGUMENTS

## 実行手順

### 1. 競合サイトの特定
- WebSearch で対象カテゴリの主要キーワードを検索する
  - 「$ARGUMENTS おすすめ」「$ARGUMENTS 選び方」「$ARGUMENTS ランキング」「$ARGUMENTS 飲み方」等
- 上位表示されている競合サイトを特定・リストアップする（5〜10サイト）
- 各サイトの種類を分類する（メディアサイト、ECサイト、メーカーサイト、個人ブログ等）

### 2. 競合コンテンツ構造の分析
- WebSearch で各競合の主要記事を調査する
- 以下の観点で分析する:
  - **記事タイトル**: キーワードの使い方、文字数、訴求ポイント
  - **見出し構成**: H2/H3の数と構成パターン
  - **コンテンツの深さ**: 文字数の推定、情報の網羅性
  - **独自性**: オリジナルコンテンツ（レビュー、取材、データ等）の有無
  - **更新頻度**: 最終更新日、更新の定期性

### 3. キーワードターゲティング分析
- 競合がターゲットにしているキーワードを特定する
- 以下のカテゴリで整理する:
  - 競合が強いキーワード（上位3位以内に複数競合）
  - 競合が弱いキーワード（上位に高品質コンテンツがない）
  - 狙い目キーワード（検索需要はあるが競合が少ない）

### 4. コンテンツギャップの発見
- 競合がカバーしていないサブトピックを特定する
- ユーザーの検索意図に対して競合が不十分な領域を発見する
- カンパイなびが差別化できるポイントを明確にする

### 5. 競合の強み・弱みの評価
- 各競合サイトについてSWOT的な評価を行う
- カンパイなびとの比較での優位点・劣位点を整理する

## エラーハンドリング

- `$ARGUMENTS` が空の場合: 「分析対象のカテゴリを指定してください。例: `/competitor-analysis 日本酒`」と案内する
- WebSearch で十分なデータが取得できない場合: 取得できた範囲で分析し、データ不足箇所を明記する
- 競合サイトが特定できない場合: より広いキーワードで検索し直す
- システムプロンプトファイルが見つからない場合: CLAUDE.md の情報をベースに Strategist の役割を遂行する

## 注意事項

- 競合サイトの分析は公開情報のみを対象とする
- 競合サイトへの誹謗中傷は行わない
- 競合のコンテンツをコピーすることは推奨しない（差別化を重視する）
- 分析結果はカンパイなびのコンテンツ改善に活用するためのものである
