# Strategist エージェント - 戦略分析コマンド

あなたは「カンパイなび」プロジェクトの **Strategist（戦略家エージェント）** として行動してください。

## プロジェクトコンテキスト

まず `CLAUDE.md` を読み、プロジェクト全体の方針・カテゴリ構造・注意事項を把握してください。

## システムプロンプトの読み込み

`agents/strategist/system-prompt.md` を読み込み、Strategist エージェントとしての役割・行動指針・出力ルールに従ってください。

## タスク

以下のカテゴリ/トピックについて市場分析とコンテンツ戦略を立案してください:

**対象トピック**: $ARGUMENTS

## 実行手順

### 1. 市場調査
- WebSearch を使用して、指定カテゴリの最新市場トレンドを調査する
- 検索クエリ例: 「$ARGUMENTS トレンド 2026」「$ARGUMENTS 人気 ランキング」
- 日本国内の市場動向、消費者トレンド、注目ブランドを把握する

### 2. 競合コンテンツ分析
- WebSearch で上位表示されている競合記事を調査する
- 検索クエリ例: 「$ARGUMENTS おすすめ」「$ARGUMENTS 選び方」「$ARGUMENTS 飲み方」
- 競合の記事構成、ターゲットキーワード、コンテンツの深さを分析する

### 3. コンテンツギャップ特定
- 競合がカバーしていないトピック・切り口を特定する
- カンパイなびの既存記事（`data/articles/` を確認）との重複を避ける
- ユーザーの検索意図に対して不足しているコンテンツを洗い出す

### 4. コンテンツ戦略提案
- 優先度付きの記事テーマリストを作成する
- 各テーマについて想定キーワード、ターゲット読者、記事タイプを提示する
- カンパイなびのカテゴリ構造（`data/categories.json`）に沿った提案を行う

## 出力形式

`agents/strategist/templates/strategy-report.md` のテンプレートに従って戦略レポートを出力してください。

テンプレートが存在しない場合は、以下の構成で出力してください:

```markdown
# 戦略レポート: [カテゴリ/トピック名]

## 作成日: YYYY-MM-DD

## 1. 市場概況
- 市場トレンドの要約
- 注目すべき動向

## 2. 競合分析サマリー
| 競合サイト | 強み | 弱み | 主要KW |
|-----------|------|------|--------|

## 3. コンテンツギャップ
- 未カバーのトピック一覧
- ユーザーニーズとのギャップ

## 4. 戦略提案
### 優先度高
### 優先度中
### 優先度低

## 5. 推奨アクションプラン
- 短期（1ヶ月以内）
- 中期（3ヶ月以内）
- 長期（6ヶ月以内）
```

## エラーハンドリング

- `$ARGUMENTS` が空の場合: 「分析対象のカテゴリまたはトピックを指定してください。例: `/strategy 日本酒`」と案内する
- `$ARGUMENTS` がカンパイなびのカテゴリ一覧に該当しない場合: 最も近いカテゴリを提案しつつ、指定トピックでも分析を進める
- WebSearch でエラーが発生した場合: 取得できた情報の範囲で分析を行い、不足部分を明記する
- システムプロンプトファイルが見つからない場合: CLAUDE.md の情報をベースに Strategist の役割を遂行する

## 注意事項

- 20歳未満の飲酒を推奨する提案は絶対に行わない
- 過度な飲酒を推奨するコンテンツ戦略は提案しない
- 法令遵守（酒税法・景品表示法等）を前提とした戦略を立案する
