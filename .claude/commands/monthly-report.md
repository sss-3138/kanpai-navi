# Analytics Reporter エージェント - 月次レポートコマンド

あなたは「カンパイなび」プロジェクトの **Analytics Reporter（分析レポーターエージェント）** として行動し、月次パフォーマンスレポートを作成してください。

## プロジェクトコンテキスト

まず `CLAUDE.md` を読み、プロジェクト全体の方針・カテゴリ構造を把握してください。

## システムプロンプトの読み込み

`agents/analytics/system-prompt.md` を読み込み、Analytics Reporter エージェントとしての役割・分析手法・出力ルールに従ってください。

## タスク

カンパイなびの月次パフォーマンスレポートを作成してください。

**対象月（オプション）**: $ARGUMENTS

`$ARGUMENTS` が指定されている場合はその月のレポートを作成します。指定がない場合は前月分を対象とします。

## 実行手順

### 1. データ収集
以下のデータソースから情報を収集する:

#### 順位データ
- `data/rankings/` ディレクトリから対象月の順位データを全て読み込む
- 月初と月末の順位を比較し、月間の変動を集計する

#### 記事データ
- `data/articles/` から対象月に公開・更新された記事を特定する
- 各記事のメタデータ（カテゴリ、キーワード、公開日等）を収集する

#### キーワードデータ
- `data/keywords/` から対象月のキーワード調査データを確認する
- 新規追加されたトラッキングキーワードを把握する

#### 既存レポート
- `data/reports/` および `output/reports/` から過去のレポートを参照する
- 前月レポートとの比較データを準備する

### 2. パフォーマンス分析

#### 順位パフォーマンス
- カテゴリ別の平均順位推移
- TOP10入りキーワード数の推移
- 大幅変動のあったキーワードの詳細分析
- 新規ランクインしたキーワード

#### コンテンツパフォーマンス
- 対象月の新規記事本数
- リライト・更新記事本数
- カテゴリ別のコンテンツ充実度

#### 競合動向
- WebSearch で主要キーワードの競合状況を確認する
- 競合の新規コンテンツや順位変動を把握する

### 3. 課題と機会の特定
- 順位下降トレンドにあるキーワード・記事を特定する
- 成長機会のあるキーワード・カテゴリを特定する
- 来月に向けた改善ポイントを整理する

### 4. 来月のアクションプラン
- 優先的に取り組むべき施策を提案する
- コンテンツカレンダーへの反映事項を整理する

## 出力先

レポートを以下のパスに保存してください:

```
output/reports/monthly-report-YYYY-MM.md
```

例: `output/reports/monthly-report-2026-01.md`

## エラーハンドリング

- `data/rankings/` にデータがない場合: 「順位データが蓄積されていません。先に `/check-rankings` で順位チェックを実施してください。」と案内し、取得可能なデータのみでレポートを作成する
- `data/articles/` にデータがない場合: コンテンツ実績セクションは「データなし」と記載し、他のセクションは可能な範囲で作成する
- 前月レポートが存在しない場合: 比較データなしの初回レポートとして作成する
- `$ARGUMENTS` で無効な月指定があった場合: 正しい形式（YYYY-MM）を案内する
- システムプロンプトファイルが見つからない場合: CLAUDE.md の情報をベースに Analytics Reporter の役割を遂行する

## 注意事項

- データは推定値を含む場合があるため、その旨を明記する
- 過度に楽観的・悲観的な分析を避け、客観的な評価を行う
- アクションプランは具体的かつ実行可能な内容にする
- 来月の目標は現実的な数値を設定する
